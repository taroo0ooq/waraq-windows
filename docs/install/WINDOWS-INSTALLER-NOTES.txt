Waraq for Windows — Installer notes (WRQ-WIN-002 / HF1-D2)

LICENSE
  GNU GPL v3 — see LICENSE and NOTICE in the install folder and
  https://github.com/taroo0ooq/waraq-windows

PRODUCT
  This Setup installs the current WinUI 3 parity app (src/), not the
  archived WPF MVP under archive/wrq-win-001/.

START MENU (HF1-D2)
  Start shows a single "Waraq for Windows" shortcut that launches the app.
  There is NO Uninstall entry in the Start Menu group (users were opening
  uninstall by mistake). Uninstall via Windows Settings → Apps.

CODE SIGNING (SELF-SIGNED)
  Setup and application may be Authenticode-signed with a *project
  self-signed* certificate (not EV/OV). SmartScreen may still warn.

  Optional: import WaraqWindows-CodeSigning.cer from official GitHub
  Release/CI artifacts only into Trusted Publishers if you accept the risk.

PREREQUISITES
  Self-contained payload: .NET 8 runtime and Windows App SDK components
  are bundled. No separate Desktop Runtime install for the default build.
  No third-party download mirrors.
